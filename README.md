# الموقر التجارية

منصة شركة الموقر التجارية — توريد وتجهيز المؤسسات في المملكة الأردنية، مع نظام متابعة الشكاوى والمهام الميدانية.

## الميزات

- صفحة تعريفية احترافية (عربي / إنجليزي)
- تسجيل دخول للسوبر أدمن والموظفين الميدانيين
- تقديم شكاوى من المؤسسات (بدون تسجيل) مع رفع صور
- لوحة تحكم — توكيل موظف → متابعة → إغلاق من السوبر أدمن
- إثبات زيارة بالموقع (GPS)
- تصميم متجاوب للجوال
