# الموقر التجارية

منصة إدارة شكاوى المكتبات لشركة الموقر التجارية — توريد وتجهيز المكتبات في المملكة الأردنية.

## الميزات

- صفحة تعريفية بتصميم 3D
- تسجيل دخول للمستخدمين والموظفين
- تقديم شكاوى مع رفع صور
- لوحة تحكم بصلاحيات حسب الفرع والدور
- دورة موافقات: توكيل → حل → موافقة أدمن → إغلاق نهائي
- إثبات زيارة بالموقع (GPS)
- إشعارات + دعم عربي / إنجليزي
